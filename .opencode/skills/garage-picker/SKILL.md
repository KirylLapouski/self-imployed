# Garage Picker

Скилл для регулярного подбора гаражей в Витебске под сдачу физлицу (фиксированный подоходный налог 19 BYN/мес., статус «занятого»). Работает по методике из `doc.md`: бюджет, центр, ликвидный размер, оценка 0–100.

## Быстрый запуск

```bash
node .opencode/skills/garage-picker/scripts/collect.mjs
```

Опционально:

```bash
node .opencode/skills/garage-picker/scripts/collect.mjs --top 5 --max-price 30000
node .opencode/skills/garage-picker/scripts/collect.mjs --no-realt
node .opencode/skills/garage-picker/scripts/collect.mjs --near "Офицерская 4А/13" --max-min 30
```

Скрипт без зависимостей (Node 18+), печатает путь к отчёту и топ-5 в консоль.

`--near` — режим «рядом с ориентиром»: точка старта геокодируется через OSM/Nominatim, объекты фильтруются по времени езды (`--max-min`, по умолчанию 30 мин), а в отчёт добавляется раздел «Маршрут на день» — связка из 3 ближайших друг к другу объектов с лучшими оценками, чтобы посмотреть их за один выезд.

## Что делает

1. **Собирает** объявления:
   - Kufar: `https://re.kufar.by/l/vitebsk/kupit/garazh` (все страницы, ~100 объявлений);
   - Realt: `https://realt.by/vitebsk-region/sale/garage/garazh/` (~15 объявлений).
2. **Нормализует**: цена в BYN, площадь, адрес, координаты, расстояние до центра, фичи (яма, подвал, свет, охрана), текст.
3. **Фильтрует**: цена 18 000–32 000, площадь 15–40 м², ≤ 6 км от центра (или ≤ `--max-min` от `--near`), стоп-слова (металлический «без места», доля, второй этаж, «крыша под замену»), дедупликация Kufar/Realt.
4. **Оценивает** каждый объект 0–100:
   - юр. чистота — 25% (ключевые слова: «приватизирован», «техпаспорт», «без долгов», «собственник»);
   - локация — 20% (расстояние до центра);
   - техсостояние — 20% (яма, подвал, свет, охрана, кирпич/ж-б, сухая крыша);
   - цена — 20% (абсолютная цена + BYN/м²);
   - ликвидность — 15% (площадь 18–27 м², тип объекта).
5. **Считает аренду и доходность**: медиана текущих ставок аренды гаражей в Витебске (Kufar, 1 страница) + поправка на фичи; доходность = (аренда×12 − налог 228 − взносы ГСК 360 − резерв 12%) / цена.
6. **Формирует отчёт** `reports/garages-vitebsk-<YYYY-MM-DD>.md`:
   - дата и время запуска, источники, сколько просканировано;
   - таблица топ-5 + карточка каждого объекта (цена, м², адрес, расстояние, фичи, оценка аренды/доходности, критерии, ссылка);
   - маршрут на день (в режиме `--near`);
   - 3 следующих кандидата;
   - статистика отсева по причинам;
   - методика и ограничения.

## Формат отчёта (контракт)

- Файл: `reports/garages-vitebsk-YYYY-MM-DD.md` (перезаписывается при повторном запуске в тот же день).
- В шапке обязательно: **дата и время выполнения**.
- В топе — не более `--top` объектов (по умолчанию 5), отсортированы по оценке; при равенстве — дешевле выше.
- У каждого объекта — рабочая ссылка на объявление и источник/ID.
- Никаких выдуманных объектов: только то, что получено в момент запуска.

## Настройка

Все параметры — в `.opencode/skills/garage-picker/config.json`:

- `budget`, `area`, `maxDistanceKm` — рамки отбора;
- `weights` — веса критериев (сумма 100);
- `taxPerMonthByn`, `hoaPerMonthByn`, `reserveShare` — экономика;
- `centerStreets` — приблизительное расстояние до центра по названию улицы (для Realt, где нет координат);
- `negativeKeywords` — стоп-слова.

Менять city/город — через `--city` (структура URL Kufar/Realt одинаковая для областных центров, но `centerStreets` нужно адаптировать).

## Если источники недоступны

1. Скрипт напечатает ошибку источника и продолжит с тем, что доступно.
2. Если оба источника недоступны (антибот/сеть) — используй `webfetch` на те же URL и пройди рубрику вручную:
   - возьми 10–15 объявлений в бюджете;
   - отбрось стоп-факторы;
   - оцени по 5 критериям и запиши тот же отчёт с датой.
3. Не подменяй данные прошлых запусков «свежими» — всегда указывай фактическую дату.

## Правила интерпретации

- Юр. чистота и техсостояние — **прокси по тексту объявления**, а не проверка документов. В отчёте это указано; при общении с продавцом обязательна проверка свидетельства, техпаспорта, ЕГР и справки ГСК.
- Оценка аренды — рыночный ориентир, а не гарантия: проверяйте по 5–10 аналогичным объявлениям.
- Отчёт не является юридической консультацией.
- Если пользователь просит «просто 5 вариантов», покажи таблицу из отчёта и 1–2 sentences по каждому; полный отчёт — по ссылке.
